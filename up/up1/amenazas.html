1.4 Vulnerabilidades y amenazas

0226 · UP1: Fundamentos de la SI

¿Qué es una vulnerabilidad?

Una vulnerabilidad es un fallo o deficiencia en un sistema que puede ser explotada por un atacante. Pueden ser más o menos actuales, conocidas y con distintos niveles de gravedad.

Tipos de amenazas

Ingeniería social y Phishing

Manipulación psicológica para engañar a los usuarios y conseguir credenciales, pagos o descargas maliciosas. Variantes: spear phishing (dirigido), smishing (SMS), vishing (llamadas).

Malware (Software malicioso)

TipoDescripción
RansomwareCifra archivos y exige rescate económico
TroyanosApariencia inofensiva, instala puertas traseras
VirusSe replica infectando archivos ejecutables
GusanosSe propaga automáticamente por la red

Denegación de Servicio (DoS/DDoS)

Saturación de tráfico para dejar un servicio inaccesible. Utiliza redes de dispositivos infectados (botnets).

Ataques web

  • SQL Injection: inserción de código en bases de datos.
  • XSS: ejecución de scripts maliciosos en navegadores.
  • CSRF: manipulación de sesiones de usuario.

Ataques a redes

  • ARP Poisoning: manipulación de tablas ARP.
  • DNS Poisoning: redirección de tráfico.
  • Man-in-the-Middle: interceptación de comunicaciones.

Tipos de atacantes

TipoDescripción
HackersRealizan ataques intencionados contra sistemas
CrackersUsan ingeniería social para enviar malware
SniffersInterceptan y analizan tráfico de red
LammerAficionado que presume de conocimientos que no tiene, usa scripts sin entenderlos

Atención: El término "hacker" originalmente se usaba para alguien con grandes conocimientos técnicos. Hoy en sentido peyorativo se refiere a atacantes maliciosos.

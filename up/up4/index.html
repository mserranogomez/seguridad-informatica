UP4: Seguridad en el Sistema Operativo

0226 · RA3 · 2ª Evaluación

Resultado de aprendizaje

RA3: Aplica mecanismos de seguridad activa, describiendo sus características y relacionándolas con las necesidades de uso del sistema informático.

Contenidos

Políticas de acceso

  • Contraseñas: Política de contraseñas, complejidad, caducidad.
  • BIOS/UEFI: Contraseña de administrador y de usuario.
  • Gestor de arranque: Protección de GRUB.
  • Gestores de contraseñas: Herramientas y buenas prácticas.

Cifrado de información

  • Cifrado de directorios, particiones y discos.
  • Herramientas: BitLocker, eCryptfs, LUKS.

Permisos

  • DAC: Control de acceso discrecional (chmod, ACL, SUID, SGID, Sticky Bit).
  • MAC: Control de acceso obligatorio (SELinux, AppArmor).
  • RBAC: Control de acceso basado en roles.
  • Elevación de privilegios: UAC, sudo/sudoers.

Cuotas de disco

  • Configuración en Windows y Linux.
  • Límites de espacio por usuario.

Chroot

  • Jaulas para aislar procesos.
  • Usos: recuperación de contraseñas, seguridad de servidores.

Montar un sistema de cuotas en Linux y Windows.

UD5: Seguridad en Redes

0226 · 25 horas · Resultado de Aprendizaje 4

Resultado de aprendizaje

Asegura la privacidad de la información transmitida en redes informáticas describiendo vulnerabilidades e instalando software específico.

Esta UD cubre los criterios de evaluación a), d), e) y h) del RA4, dedicados a seguridad en redes.

Contenidos

1. Inventario y control de servicios de red

  • ¿Por qué inventariar? no se puede proteger lo que no se conoce.
  • Herramientas de escaneo: nmap para descubrir hosts y servicios activos.
  • Puertos y servicios: puertos abiertos, cerrados y filtrados.
  • Documentación: mantenimiento de un inventario actualizado de la red.

2. Monitorización de redes cableadas

  • ¿Qué es la monitorización? observación del tráfico de red para detectar anomalías.
  • Herramientas: Wireshark (análisis de paquetes), tcpdump.
  • Amenazas: ataques man-in-the-middle, sniffing, poisoning ARP.
  • Medidas de protección: segmentación de red, cifrado, port security.

3. Seguridad en redes inalámbricas

  • Vulnerabilidades del WiFi: WEP (obsoleto), WPA, WPA2, WPA3.
  • Protocolos de cifrado: TKIP vs. AES-CCMP.
  • Autenticación: PSK (pre-shared key) vs. Enterprise (RADIUS).
  • Seguridad de puertos: MAC filtering, 802.1X.
  • Medidas adicionales: ocultar SSID (y por qué no es suficiente), segmentación VLAN.

4. Cortafuegos (firewall)

  • ¿Qué es un cortafuegos? barrera entre redes que filtra el tráfico según reglas.
  • Tipos:
    • Filtrado de paquetes: reglas basadas en IP, puerto y protocolo.
    • Stateful: conoce el estado de las conexiones.
    • Proxy: actúa como intermediario.
    • Next-generation: inspección profunda de paquetes.
  • iptables / nftables: cortafuegos nativo de Linux.
  • UFW (Uncomplicated Firewall): interfaz sencilla para iptables.
  • Windows Firewall: configuración básica.

Prácticas

Práctica 5.1: Escaneo de red con nmap

Realizar un escaneo de la red local para descubrir hosts activos, puertos abiertos y servicios ejecutándose.

# Escaneo básico de la red
nmap -sn 192.168.1.0/24

# Escaneo de puertos y servicios de un host
nmap -sV 192.168.1.100

# Escaneo agresivo (con detección de SO)
nmap -A 192.168.1.100

Práctica 5.2: Análisis de tráfico con Wireshark

Capturar tráfico de red con Wireshark y analizar los paquetes para identificar protocolos, direcciones IP y posibles anomalías.

Práctica 5.3: Configuración de UFW

Configurar UFW en Linux para permitir o denegar tráfico según un conjunto de reglas. Verificar que el cortafuegos funciona correctamente.

# Activar UFW
sudo ufw enable

# Permitir SSH
sudo ufw allow ssh

# Permitir tráfico web
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Ver reglas
sudo ufw status verbose

# Denegar todo lo no permitido
sudo ufw default deny incoming
sudo ufw default allow outgoing

Práctica 5.4: Configuración de iptables

Crear reglas de cortafuegos con iptables para filtrar tráfico por dirección IP, puerto y protocolo.

# Ver reglas actuales
sudo iptables -L -n

# Bloquear una IP
sudo iptables -A INPUT -s 192.168.1.100 -j DROP

# Permitir tráfico HTTP
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# Guardar reglas
sudo iptables-save > /etc/iptables/rules.v4

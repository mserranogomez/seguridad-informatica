UD3: Seguridad Activa y Software Malicioso

0226 · 15 horas · Resultado de Aprendizaje 3

Resultado de aprendizaje

Aplica mecanismos de seguridad activa describiendo sus características y relacionándolas con las necesidades de uso del sistema informático.

Contenidos

1. Software malicioso: clasificación

  • Virus: código que se adjunta a un programa y se replica al ejecutarse.
  • Troyano: programa que aparenta ser útil pero realiza funciones maliciosas.
  • Ransomware: cifra los datos de la víctima y exige un rescate para descifrarlos.
  • Spyware: recopila información del usuario sin su consentimiento.
  • Adware: muestra publicidad no deseada.
  • Rootkit: oculta su presencia en el sistema y permite acceso remoto.
  • Keylogger: registra las pulsaciones del teclado para robar contraseñas.
  • Gusano: se propaga automáticamente por la red sin necesidad de un archivo huésped.

2. Actualizaciones y parches de seguridad

  • Importancia de mantener el sistema operativo y el software actualizados.
  • Parches de seguridad: qué son y cuándo se publican.
  • Actualizaciones automáticas vs. manuales.
  • Gestión de parches en entornos empresariales.

3. Verificación de origen y autenticidad

  • Sumas de comprobación: SHA-256, MD5 (y por qué MD5 ya no es seguro).
  • Firmas digitales: cómo verificar que un software no ha sido manipulado.
  • Fuentes oficiales: importancia de descargar solo de repositorios oficiales.

4. Herramientas de protección

  • Antivirus: ClamAV (open source), funcionamiento en tiempo real vs. análisis bajo demanda.
  • Antimalware: herramientas complementarias para detección profunda.
  • Detección de rootkits: rkhunter, chkrootkit.
  • Firewall de host: protección a nivel de equipo.

5. Recuperación de datos

  • TestDisk: recuperación de particiones perdidas.
  • PhotoRec: recuperación de archivos eliminados.
  • Principios de recuperación: no sobrescribir el disco, actuar con rapidez.

Prácticas

Práctica 3.1: Análisis con ClamAV

Instalar ClamAV en Linux y realizar un análisis completo del sistema. Interpretar los resultados y tomar medidas ante las amenazas detectadas.

sudo apt update && sudo apt install clamav
sudo freshclam
sudo clamscan -r /home

Práctica 3.2: Verificación de integridad

Descargar un archivo de un repositorio oficial y verificar su integridad usando la suma de comprobación SHA-256 proporcionada.

sha256sum archivo_descargado.zip
# Comparar con el hash proporcionado por el sitio oficial

Práctica 3.3: Recuperación de datos con TestDisk

Simular la eliminación accidental de una partición y recuperarla usando TestDisk en un entorno controlado.
